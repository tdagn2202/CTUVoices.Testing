# Test Data

Test data thủ công được quản lý chủ yếu ở `xlsx/`. Mỗi dòng dữ liệu có một mã
`TD_*` ổn định và mô tả rõ chức năng sử dụng, loại dữ liệu, giá trị đầu vào,
kết quả dự kiến và trạng thái chuẩn bị.

File media và tài liệu RAG được lưu ở thư mục tương ứng; workbook chỉ tham chiếu
tới đường dẫn tương đối của chúng.
