# Authentication Test Suite

## Phạm vi chức năng

1. Register.
2. Login.
3. Forgot Password.
4. Verify Reset OTP.
5. Reset Password.
6. Change Password.

## Điều kiện trước khi thực thi

- Test case đã được review.

- Hệ thống CTU Voices đang chạy trên localhost.
- Trạng thái tài khoản cần dùng đã được xác định.
