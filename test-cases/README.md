# Test Cases

Test case được chia theo cụm chức năng. Mỗi test case chỉ xác minh một hành vi
chính và sử dụng ID dạng `TC-XXX`.

Workbook test case sử dụng các cột:

1. Test Case ID.
2. Cụm chức năng.
3. Chức năng.
4. Mô tả.
5. Điều kiện tiên quyết.
6. Test Data ID.
7. Các bước thực hiện.
8. Kết quả mong đợi.
9. Kết quả thực tế.
10. Trạng thái.
11. Evidence.
12. Ghi chú.
